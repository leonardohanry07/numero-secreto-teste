<h2>📖 Sobre o projeto</h2>

<p>
  O <strong>Jogo do Número Secreto</strong> é uma aplicação
  interativa desenvolvida com HTML, CSS e JavaScript.
</p>

<p>
  O objetivo é descobrir um número gerado aleatoriamente
  pelo sistema. A cada tentativa, o jogador recebe dicas
  para descobrir o número correto.
</p>

<hr>

<h2>🚀 Funcionalidades</h2>

<ul>
  <li>🎲 Geração de números aleatórios.</li>
  <li>🔢 Campo para inserir palpites.</li>
  <li>💡 Dicas indicando se o número é maior ou menor.</li>
  <li>🏆 Mensagem ao acertar o número secreto.</li>
  <li>🔄 Possibilidade de iniciar uma nova partida.</li>
</ul>

<h2>🎮 Como jogar</h2>

<ol>
  <li>Abra o jogo no navegador.</li>
  <li>Digite um número no campo indicado.</li>
  <li>Clique no botão para verificar seu palpite.</li>
  <li>Observe as dicas apresentadas.</li>
  <li>Continue tentando até acertar!</li>
</ol>
